01 / EMBED

Tokens become points

Each token is projected to a coordinate in N-dimensional space. There is no order, no index, no positional encoding — only position.

02 / INFLUENCE

Everything pulls on everything

Every point exerts force on every other, weighted by spatial proximity and local density. Influence is simultaneous, not directional.

03 / ITERATE

The cloud relaxes

The model applies learned transformations between cloud states, stepping the system toward lower energy. Harder problems simply take more steps.

04 / CONVERGE

Equilibrium is the answer

When motion falls below threshold, the cloud has settled. Its final configuration is decoded directly — no next-token prediction anywhere in the loop.

What's different

A reasoning system with fewer assumptions.

By removing the scaffolding of sequence modeling, MDPCR trades familiar machinery for a small set of physical rules.

No positional encoding

Meaning lives in geometry. Where a point sits relative to its neighbours is its context — nothing is injected to fake an order.

no qkv

No linear attention

Interaction is governed by spatial proximity and density fields, not query–key–value projections.

adaptive

No fixed depth

No preset layer count. It iterates until convergence, so compute scales with difficulty.

Cloud-to-cloud transformations

The model learns how one configuration of points maps to the next — transformations of state, rather than predictions of the next token.

parallel

Simultaneous influence

All points update together each step — a global relaxation, not a backward-only pass.

interpretable

Equilibrium as output

The answer is a stable state, not a sampled string. Convergence is a measurable, inspectable property of the system — you can watch the reasoning settle and know exactly when it's done.

Why it matters

If reasoning is spatial, computation should be too.

A

Effort matches difficulty

Easy inputs settle in a few steps; hard ones take more. Depth becomes a property of the problem, not a hyperparameter.

B

You can watch it think

Convergence is observable. The trajectory toward equilibrium is a window into the reasoning process itself.

C

A different bet

Most progress refines the transformer. MDPCR asks what happens if we change the substrate entirely.
